## 🎯 Objetivo

O objetivo deste repositório é documentar minha jornada de aprendizado na linguagem Java, construindo uma base sólida em **Orientação a Objetos**, **Estruturas de Dados**, **Classes Utilitárias** e **Recursos Modernos do Java (Java 8+)**, preparando-me para o desenvolvimento de aplicações robustas no ecossistema Spring.

---

## 📚 Tópicos Abordados & Conteúdos Praticados

### 🟢 Fundamentos da Linguagem
- [x] Tipos primitivos, variáveis e operadores
- [x] Estruturas condicionais (`if/else`, `switch case`)
- [x] Estruturas de repetição (`for`, `while`, `do-while`)
- [x] Estruturas de dados básicas: Arrays unidimensionais e multidimensionais

### 🔵 Programação Orientada a Objetos (POO)
- [x] Classes, Atributos, Métodos e Parâmetros
- [x] Sobrecarregamento de métodos e construtores
- [x] Modificadores de Acesso (`public`, `private`, `protected`, default)
- [x] Associação entre classes (Um para Um, Um para Muitos, Muitos para Muitos)
- [x] Herança e Polimorfismo
- [x] Sobrescrita de métodos (`@Override`) e modificador `final`
- [x] Classes e Métodos Abstratos
- [x] Interfaces e Enumerações (`enum`)

### 🔴 Tratamento de Erros e Exceções
- [x] Hierarquia de Exceções (`Throwable`, `Exception`, `RuntimeException`)
- [x] Bloco `try-catch-finally` e `try-with-resources`
- [x] Lançamento de exceções (`throw` / `throws`)
- [x] Criação de Exceções Customizadas

### 🟣 Classes Utilitárias e Recursos Essenciais
- [x] **Classes Wrapper** (Autoboxing / Unboxing)
- [x] **Manipulação de Strings**: `String`, `StringBuilder` e `StringBuffer`
- [x] **Data e Hora**: `Date`, `Calendar`, `LocalDate`, `LocalTime`, `LocalDateTime`, `Instant`, `Duration`, `Period` e `DateTimeFormatter`
- [x] **Formatação de dados** (`Locale`, `NumberFormat`)

### 🟡 Coleções e Generics
- [x] **Listas:** `ArrayList`, `LinkedList`, `Vector`
- [ ] **Conjuntos:** `HashSet`, `TreeSet`, `LinkedHashSet`
- [ ] **Mapas:** `HashMap`, `TreeMap`, `LinkedHashMap`
- [ ] **Ordenação de coleções** (`Comparable` vs `Comparator`)
- [ ] **Generics:** Tipos genéricos e Wildcards (`? super`, `? extends`)

### ⚡ Java Moderno (Java 8+)
- [ ] **Lambdas & Interfaces Funcionais** (`Predicate`, `Consumer`, `Function`, `Supplier`)
- [ ] **Method References**
- [ ] **Streams API:** Filtragem (`filter`), Mapeamento (`map`), Redução (`reduce`), Coleta (`collect`), Agrupamento (`groupingBy`)
- [ ] **Optional:** Tratamento elegante de valores nulos e evitação do `NullPointerException`

## ⚙️ Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter o **JDK 25** (ou superior) instalado na sua máquina.

```bash

git clone [https://github.com/GustavoTamaninis/java-dev-dojo.git](https://github.com/GustavoTamaninis/java-dev-dojo.git)

# 2. Acesse a pasta do projeto
cd java-dev-dojo

# 3. Abra o projeto na sua IDE de preferência e execute a classe com o método main desejado.
